## 功能特性

### 📊 概览工作台
- 实时统计在册物料数、有效批次数、库存总值
- **低库存预警**：物料库存低于设定下限时高亮提醒
- **临期预警**：批次有效期进入预警窗口（默认 30 天）时提醒
- **过期预警**：批次有效期已过但仍有剩余时告警
- 近 7 日出入库趋势图、分类库存分布

### 📦 库存作业
- **扫码入库**：兼容所有 USB 扫码枪（模拟键盘输入），扫描条码自动带出物料信息
- **智能出库**：自动按「先到期先出（FEFO）」推荐批次，也可手动指定
- **批次报废**：支持按批号作废，记录报废原因
- **出入库流水**：全量操作记录，支持按类型 / 时间 / 关键字检索

### 🗂 档案管理
- **物料档案**：试剂、耗材的名称、规格、厂家、供应商、存储条件、预警参数
- **批次库存**：按批号管理库存，记录生产日期、有效期、存放位置、单价
- **批次追溯**：可视化时间轴展示单个批次的完整生命周期（入库 → 出库 → 报废）

### 📈 报表中心
- 出入库统计（按物料维度）
- 经手人用量统计（Top 排行）
- 效期分析（临期 / 过期批次列表）
- 一键导出 Excel（多 Sheet 支持，带表头样式与筛选器）

### ⚙️ 系统管理
- **账号管理**：三级角色（管理员 / 录入员 / 只读用户）
- **操作日志**：所有增删改与登录行为自动留痕
- **数据备份**：一键将数据库备份到指定路径
- **数据恢复**：从备份文件还原（含合法性校验）
- **修改密码**：用户可自助修改

## 技术栈

| 层级 | 技术 | 说明 |
|---|---|---|
| 桌面框架 | **Electron 32** | 跨平台桌面应用容器 |
| 前端框架 | **Vue 3.4** | Composition API + `<script setup>` |
| UI 组件库 | **Element Plus 2.8** | 中文语言包 |
| 状态管理 | **Pinia 2** | 用户会话管理 |
| 路由 | **Vue Router 4** | Hash 模式 + 权限守卫 |
| 构建工具 | **Vite 5** | 极速冷启动与 HMR |
| 本地数据库 | **better-sqlite3** | 同步 API，性能优异 |
| Excel 导出 | **ExcelJS** | 支持样式、多 Sheet、筛选 |
| 打包工具 | **electron-builder** | 生成 NSIS 安装包 / 便携版 |
| CI/CD | **GitHub Actions** | 自动编译 Windows 安装包 |
